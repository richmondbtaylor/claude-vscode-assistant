# Presentation Feedback: Introduction to Prompt Engineering (Training Deck)

**Outcome Goal:** Training sessions for my team

---

## Overall Assessment

This is a solid, well-structured introductory training deck. It covers the essential building blocks of prompt engineering in a logical sequence and is appropriately scoped for a single session. The content is accurate and practical. The main opportunities for improvement are around depth, engagement, visual thinking, and making the learning stick beyond the session.

---

## Slide-by-Slide Feedback

### Slide 1: Introduction to Prompt Engineering

**Strengths:**
- The three bullet points create a clear session contract with the audience — they know what they're getting.
- "Why does prompt quality matter?" is a strong hook question that creates relevance before diving into mechanics.

**Opportunities:**
- The objectives bullet is too vague — "Objectives for today's session" is a heading, not an objective. Replace it with 2–3 specific, measurable outcomes (e.g., "By the end of this session, you'll be able to write a well-structured prompt using the RCTFC framework and improve a weak prompt through iteration").
- Consider opening with a concrete, relatable example — show a bad prompt vs. a good prompt result side-by-side to immediately demonstrate why this matters.
- The title is functional but generic. A more engaging title like "Prompts That Actually Work" would set a more energetic tone for a training audience.

### Slide 2: Anatomy of a Good Prompt

**Strengths:**
- The RCTFC framework is clear, memorable, and well-organized. The one-line descriptions are appropriately simple for a first exposure.

**Opportunities:**
- This slide is purely definitional. It needs a worked example directly on the slide or immediately following — show the five components applied to a single prompt.
- Consider a visual treatment: a layered diagram or color-coded prompt block rather than text bullets alone.
- The acronym RCTFC is not named on this slide. Make it explicit ("We call this the RCTFC framework") so it becomes an anchor learners carry forward.

### Slide 3: Common Mistakes

**Strengths:**
- Addressing mistakes before the exercise is smart instructional design. "Not iterating" is an important mindset point beginners miss.

**Opportunities:**
- Each mistake needs a one-line example to become concrete.
- "Being too vague" and "Overloading with instructions" are opposite ends of a spectrum — a visual dial or spectrum would be more memorable than a list.
- Consider reframing the title as "What Trips People Up" to reduce defensiveness in a training context.

### Slide 4: Live Exercise

**Strengths:**
- The exercise timing is correct. The specific task (cold email for SaaS) is concrete and relatable.

**Opportunities:**
- Add a time box explicitly on the slide (e.g., "8 minutes individual, 5 minutes group share").
- Consider doing one facilitator-led example before individual work to lower the barrier to entry.
- Define how sharing works — volunteer, random, or structured pairs — to prevent awkward silences.
- A brief worksheet with the RCTFC checklist would support participants with varying experience levels.

### Slide 5: Key Takeaways

**Strengths:**
- "Prompts are instructions, not searches" is the best line in the deck — precise, memorable, and paradigm-shifting. Four takeaways is the right number.

**Opportunities:**
- Add a clear post-session call to action: "This week: rewrite one prompt you use regularly using the RCTFC framework." This is missing and dramatically affects post-training behavior change.
- Pair each takeaway with a callback to the exercise so it feels earned, not abstract.
- Consider a one-page RCTFC cheat sheet as a leave-behind artifact.

---

## Priority Recommendations (Ranked)

1. Add a concrete worked example of the RCTFC framework applied to a real prompt — highest-leverage change.
2. Replace the vague "Objectives" bullet with 2–3 specific, measurable learning outcomes.
3. Add a post-session call to action on Slide 5 to drive post-training behavior change.
4. Pair each Common Mistake with a before/after example.
5. Provide time boxing and facilitation structure for the live exercise.
6. Create a one-page RCTFC reference card participants can keep.

---

## Summary

This deck has a strong backbone: the right topics, in the right order, with a practical exercise at the center. The primary gap is between stating concepts and making them concrete. Most slides tell learners what to think rather than showing what it looks like. Closing that gap with examples, visuals, and a clear post-session action will meaningfully improve both learning outcomes and participant confidence.
