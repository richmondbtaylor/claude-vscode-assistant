# Presentation Impact Enhancer Report

> **Outcome:** Training sessions for my team

---

## High-Level Presentation Feedback

This deck has a solid instructional spine — the RCTFC framework is clear, the progression from concept to exercise to takeaway makes pedagogical sense, and the content is genuinely useful for a team learning prompt engineering. The biggest opportunity is making the material more memorable and participatory: training decks live or die on whether learners walk away with something they can immediately apply, and right now the slides read more like reference notes than teaching moments. The biggest risk is density — slides like Anatomy of a Good Prompt and Common Mistakes pack in multiple concepts without anchors (analogies, examples, visuals) that help new learners retain what they've heard. Every slide needs at least one concrete example or hook to shift from "informational" to "teachable."

---

## Slide-by-Slide Suggestions

### Slide 1: Introduction to Prompt Engineering

#### Visual Improvement Ideas
- Open with a split visual: on the left, a vague, weak prompt (e.g., "Write me an email") with a mediocre AI output; on the right, a sharp, structured prompt with a strong output. This sets the visual tone and immediately answers "why does this matter?" without a single extra word.
- Use `#0A4C84` as the background for the title treatment in Lato Bold — this anchors the brand from slide one and signals a polished, intentional session rather than a quick internal deck.
- Keep the layout to two zones: a bold headline/subhead on the left, and the before/after visual on the right. Avoid centering all content, which reads as static and passive for a training context.

#### Copywriting Enhancement Recommendations
- Rewrite the slide title from "Introduction to Prompt Engineering" to something that creates forward momentum for learners: **"Your Words Are the Interface"** or **"How You Ask Changes Everything."** This is a training deck — the title should spark curiosity, not describe a topic.
- Replace "What is a prompt?" with a one-sentence answer baked directly into the slide so learners aren't left waiting: e.g., **"A prompt is every instruction you give an AI — and it's the single biggest lever you control."**
- Change "Objectives for today's session" to **"By the end of this session, you'll be able to..."** followed by two or three specific, behavior-oriented outcomes. Learners engage better when outcomes are framed as their gains, not the presenter's agenda.

### Slide 2: Anatomy of a Good Prompt

#### Visual Improvement Ideas
- Build the RCTFC framework as a vertical or horizontal anatomy diagram — five labeled blocks (Role / Context / Task / Format / Constraints) with a single-line description inside each. Color the blocks using a gradient from `#0A4C84` to `#5E97D1` to create visual hierarchy and help learners scan the structure at a glance.
- Below or beside the diagram, include one compact worked example that runs through all five components for a single prompt (e.g., building a cold email). This turns an abstract model into something immediately actionable.
- Avoid a straight bulleted list — five bullets with colons reads as a glossary, not a framework. The structure of the slide should mirror the structure of the concept.

#### Copywriting Enhancement Recommendations
- Punch up each component with the "so you can..." pattern: e.g., **"Role: Tell the AI who it is — so it matches the expertise and tone you need."**
- Add a one-line analogy: **"Think of RCTFC like a brief you'd hand a new hire — the more complete it is, the better the output."**
- Consider renaming "Constraints" to **"Guardrails"** — more intuitive for non-technical team members.

### Slide 3: Common Mistakes

#### Visual Improvement Ideas
- Reframe visually as a "Prompt Autopsy" — show a weak prompt example at the top and annotate it with callouts pointing to each mistake. More memorable than an abstract list.
- If the autopsy layout isn't feasible, use a two-column layout: left column shows the mistake label, right column shows a one-line "what this looks like in practice" example. Use `#5E97D1` as a subtle left border on each row.

#### Copywriting Enhancement Recommendations
- Make each mistake specific and recognizable: **"Vague ask: 'Write me something about our product.'"**
- Rename "Overloading with instructions" to **"Piling on: asking for five things in one prompt."**
- Add a fifth item: **"Accepting the first output."** This connects directly to Slide 5's "Iterate and test" takeaway, creating a narrative thread.

---

### Slide 4: Live Exercise

#### Visual Improvement Ideas
- Format as a three-step instruction panel using numbered blocks in `#0A4C84` circles with Lato Bold — this signals "here's what you do now" versus "here's something to read."
- Leave significant white space — learners need visual breathing room to shift from listening mode to doing mode.

#### Copywriting Enhancement Recommendations
- Add explicit time guidance: **"Step 1 (5 min): Write a cold email prompt for a SaaS product — no framework yet."**
- Rewrite Step 2: **"Step 2 (5 min): Rewrite your prompt using RCTFC. Notice what changes in the output."**
- Replace "Share results with the group" with: **"Step 3: Share one thing that surprised you about the improved output."** This drives richer debrief conversations.

---

### Slide 5: Key Takeaways

#### Visual Improvement Ideas
- Display each takeaway as a bold, standalone statement in large Lato Bold — treat this like a poster, not a list. The goal is for learners to photograph or recall it without notes.
- Use `#0A4C84` for the takeaway text and `#5E97D1` as a thin underline accent on each statement.
- Add a fifth takeaway card with a blank: **"My takeaway: ___________.** This convention significantly improves individual retention and application.

#### Copywriting Enhancement Recommendations
- "Prompts are instructions, not searches" — keep it. Strong, specific, reframes a common mental model.
- Sharpen "Clarity beats brevity" to: **"Clear beats short. Every time."** The rhythm makes it more quotable.
- Rewrite "Iterate and test" as: **"Your first prompt is a draft, not a final answer."**
- Replace "Context is everything" (a cliché) with: **"The more context you give, the less the AI has to guess."** This explains the why, which is more useful for learners internalizing the principle.
