Audit your MCP server permissions.

If you're using MCP servers, do a quick permissions audit. Check what each server can access, remove anything you're not actively using, and tighten what you can.

List every MCP server — including the ones you forgot about
Check what each one accesses — databases, APIs, file system, secrets
Remove anything you're not using — least surface area wins
Tighten what you keep — default deny, scope down, log access
