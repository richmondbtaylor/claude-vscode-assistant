If you run MCP servers, audit them this week.

Good hygiene regardless. The leak just makes it urgent. Walk the list, sign off on each one, then move on with your day.

1

Review authentication on every MCP server

Tokens, rotation, scope. Default-deny anything you can't explain in one sentence.

2

Audit what data each server exposes to Claude Code

Make sure you'd be comfortable if a screenshot of every response landed on a dashboard.

3

Tighten permissions and turn on access logging

Read-only by default. Approval gates on writes. Logs you can grep next time something feels off.
