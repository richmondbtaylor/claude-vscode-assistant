INSTALL VS CODE + CLAUDE CODE

Start Here

You need two things installed: VS Code (your editor) and the Claude Code extension inside it. That's it. Everything else runs from there.

Step 1 — Install VS Code

1

Go to code.visualstudio.com

Click the big blue Download button. Open the installer and click through — all defaults are fine. VS Code is free.

2

Open VS Code

Launch it from your Start menu or Applications folder. You'll see a welcome screen — you can close that tab.

Step 2 — Install the Claude Code extension

1

Open the Extensions panel

Click the four-square icon on the left sidebar (or press Ctrl+Shift+X on Windows, Cmd+Shift+X on Mac).

2

Search for "Claude Code"

Type it in the search box at the top. Click the result from Anthropic and hit Install.

3

Sign in to Claude

A Claude icon will appear in your left sidebar. Click it. It will ask you to log in — use your Anthropic account (the same one you use at claude.ai). You'll need a Claude Pro subscription or API access.

That's the setup VS Code is your workspace. The Claude Code panel (the Claude icon in the sidebar) is where you talk to Claude. It can read, edit, and create files on your computer — that's what makes it powerful. From here on everything happens inside VS Code.
02

SET UP YOUR WORKSPACE

5 Minutes

Claude Code reads from a special folder on your computer called .claude. This folder holds your skills, your memory, and your preferences. Think of it as Claude's brain that persists between sessions.

Open your .claude folder in VS Code

1

File → Open Folder

In VS Code, click File in the top menu, then Open Folder.

2

Navigate to your home folder and select .claude

Windows: C:\Users\YourName\.claude
Mac: /Users/YourName/.claude

If the .claude folder doesn't exist yet, Claude Code creates it automatically the first time you use it. If you can't see it, it may be hidden — on Windows enable "Show hidden items" in File Explorer.

3

Click Select Folder

VS Code will now show your .claude folder in the left panel. This is your workspace — every skill and memory file you create will live here.

Tell Claude who you are

Ask Claude to create your first memory file. Click the Claude icon in the sidebar to open the chat, then type:

Paste this into Claude "Create a memory file for me. My name is [Your Name]. I run [Your Business] at [your website]. I help [your audience] with [what you do]. My ideal client is [describe them]. I want you to always be direct, skip the fluff, and never use em dashes."

Claude will create the memory files automatically. You'll see them appear in your .claude folder. From now on, Claude remembers all of this at the start of every conversation — you never have to explain it again.

03

BUILD YOUR FIRST SKILL

Skill Builder

A skill is a saved set of instructions that Claude follows every time you trigger it. Instead of explaining a complex task from scratch each session, you build it once and invoke it with a phrase. The skill builder walks you through the whole process.

How to create a skill

1

Describe what you want the skill to do

In the Claude Code panel, say something like: "I want to build a skill that takes a video transcript and turns it into captions for Instagram, LinkedIn, and TikTok." Be specific about the input, the output, and any rules you want enforced.

2

Claude asks clarifying questions

It will ask about tone, length, format, and what it should never do. Answer honestly — the more specific you are, the better the skill performs.

3

Claude drafts and tests it automatically

The skill builder writes the skill file, runs 2-3 test cases, and opens a viewer in your browser showing you the results. You'll see the output with the skill vs. without it side by side.

4

Leave feedback and repeat

In the viewer, type what you'd change. Claude reads your notes and rewrites the skill. You keep going until it's right — usually 2-3 rounds.

5

The skill is live

Once finished, the skill sits in your .claude/skills/ folder. Claude will automatically use it whenever the situation matches — no extra steps needed.

The one rule that matters most The trigger description is the line in the skill file that tells Claude when to use it. Write it in plain language that matches how you actually talk — not formal language. If Claude isn't using your skill when it should, the trigger description is almost always why. Just rewrite it to be more specific.
04

BUILD SKILLS WITH PROMPT ANYTHING

Better Output

Before building a skill in Claude Code, use Prompt Anything to design the logic. It structures your raw idea into a precise, tested prompt — so when you hand it to the skill builder, it's already well thought out.

Think of it this way: Prompt Anything figures out what the skill should do and how it should think. The skill builder then locks that thinking into a repeatable file.

The workflow

Go to promptanything.io

Log in or create a free account. This is where you'll design the prompt logic before turning it into a skill.

Describe your task in plain language

Type what you want Claude to do — the same way you'd explain it to a person. Example: "I want an agent that finds people on Reddit asking for AI automation help and scores them by how likely they are to buy."

Prompt Anything structures it for you

It applies a proven framework (CRISPE, CLEAR, STAR, etc.) to turn your messy description into a clear, structured prompt. You'll see sections like Role, Context, Steps, and Output Format appear automatically.

Test it directly in the tool

Run the prompt against Claude, GPT, or Gemini right inside Prompt Anything. See what you get. Adjust the wording until the output looks exactly right.

Bring it to Claude Code as a skill

Copy your refined prompt. Open Claude Code in VS Code and say: "Turn this into a skill." Paste the prompt. The skill builder takes it from there — testing, iterating, and locking it into your .claude/skills/ folder.

Add your hard rules

Once the skill is built, tell Claude what it should never do. Example: "Never suggest reaching out to someone who already solved their problem. Never use corporate buzzwords." These guardrails get added to the skill file and enforce your standards on every run.

Why this order matters Skipping Prompt Anything and going straight to the skill builder works — but the skill usually needs more rounds of iteration to get right. Designing the prompt logic first in Prompt Anything cuts that back to one or two rounds. It's a 10 minute investment that saves 30.

SET UP THE LEAD AGENT

The Main Event

This is the agent that runs every morning and finds people actively looking for your services. It watches Reddit, the web, and n8n Community Jobs — scores every post with AI — and sends the best ones to your Slack and Google Sheet.

What you'll need before starting

1

An Anthropic API key

Go to console.anthropic.com → API Keys → Create Key. This lets the agent use Claude to score leads. You'll be charged a tiny amount per run — typically under $0.10/day.

2

A Slack webhook URL

In Slack: click your workspace name → Settings → Integrations → Incoming Webhooks → Add New. Copy the webhook URL — it starts with https://hooks.slack.com/...

3

A Google Sheet

Create a new blank Google Sheet. Copy the ID from the URL — it's the long string between /d/ and /edit in your browser address bar.

4

Google API credentials

Go to console.cloud.google.com → New Project → Enable the Google Sheets API and Google Drive API → Create OAuth 2.0 credentials → Download the credentials.json file. Save it somewhere you'll remember.

Brave Search API (optional but recommended) The agent searches the web for leads. Without a key it uses DuckDuckGo, which sometimes rate-limits. Get a free Brave Search API key at brave.com/search/api — the free tier gives 2,000 searches/month which is more than enough.

Install and configure the agent

Open the Claude Code panel in VS Code and say:

Paste this into Claude "Help me set up the bishop-research-agent. Walk me through installing the dependencies, creating my .env file with my API keys, and running it for the first time."

Claude will guide you through each step. When it asks for your keys, have them ready. Here's what goes in the .env file:

ANTHROPIC_API_KEY Required
From console.anthropic.com → API Keys
SLACK_WEBHOOK_URL Required
From Slack → Settings → Incoming Webhooks
GOOGLE_OAUTH_CREDENTIALS Required
Path to the credentials.json file you downloaded from Google Cloud
GOOGLE_SHEET_ID Required
The long ID from your Google Sheet URL
BRAVE_API_KEY Optional
From brave.com/search/api — free tier, 2,000 queries/month

Customize it for your business

Open config.py in VS Code. Three things to update:

config.py — change these three things
# 1. Tell Claude what your business does so it knows what a good lead looks like
BISHOP_AI_CONTEXT = """
We are [Your Company]. We help [your audience] with [your service].
Our product [Product Name] costs $X/month and helps people [outcome].
Ideal client: [describe them — industry, size, pain points].
"""

# 2. Subreddits where your ideal clients hang out
REDDIT_SUBREDDITS = [
    "entrepreneur", "smallbusiness", "marketing",
    # Add more based on your niche
]

# 3. Keywords that signal someone needs your help
REDDIT_KEYWORDS = [
    "looking to hire", "need help with", "anyone recommend",
    # Use phrases your clients actually type when they're stuck
]

How the scoring works

Every post gets two AI scores. Posts above 50 on both land in your Sheet.

Relevance 90-100
Contact Now

Actively asking for help, mentions budget, or ready to hire right now

Relevance 70-89
Strong Lead

Struggling with a problem you solve, asking for recommendations

Relevance 50-69
Warm Lead

In the right space, showing early signs of needing help

Relevance 0-49
Filtered Out

Articles, tutorials, already-solved problems — never hits your Sheet

Test it first, then schedule it

Before scheduling the daily run, test it manually. In VS Code, open a terminal (Ctrl+`) and run:

VS Code Terminal
cd bishop-research-agent
python main.py --once --reddit-only   # Quick test — Reddit only
python main.py --once                  # Full run when you're ready

Check your Google Sheet. If leads are showing up and scoring makes sense, schedule it.

Schedule the daily run

Windows — Task Scheduler Search "Task Scheduler" in the Start menu → Create Basic Task → Name it "Lead Agent" → Trigger: Daily at 7:00 AM → Action: Start a program → point it at run-daily.bat in the agent folder. Done. You'll wake up to fresh leads in your Sheet every morning.
Mac — Cron Job Open Terminal and type crontab -e. Add this line:

0 7 * * * cd /path/to/bishop-research-agent && source venv/bin/activate && python main.py --once

Save and close. The agent runs at 7AM every day.

Troubleshooting

ProblemFix

0 results from web searchDuckDuckGo rate limited you — add a Brave API key to your .env
Slack not getting alertsConfirm the SLACK_WEBHOOK_URL in your .env matches exactly what Slack gave you
Seeing too many low-quality leadsRaise MIN_RELEVANCE_FOR_SHEETS from 50 to 70 in config.py
