01

INSTALL VS CODE

Start Here

VS Code is a free editor made by Microsoft. You don't need to know how to code to use it — think of it as the window where you'll talk to Claude and see everything Claude does on your computer.

Download and install

1

Go to code.visualstudio.com

Click the big blue Download button. The site automatically detects whether you're on a Mac or PC. VS Code is completely free and always will be.

2

Run the installer

Open the downloaded file. On Mac: a window opens — drag the VS Code icon into your Applications folder, then eject the window. On Windows: an installer opens — click Next through every screen and hit Install at the end. All default options are correct.

3

Open VS Code

Launch it from your Applications folder on Mac or your Start menu on Windows. A welcome tab will open — you can close it. VS Code is ready.

That's step one done VS Code is just a window right now. The next step installs Claude inside it — that's what makes it useful.
02

INSTALL CLAUDE CODE

The AI Part

Claude Code is an extension that runs inside VS Code. Once installed, Claude can read files on your computer, create new ones, run tasks, and remember things between every session. It's more capable than the claude.ai website because it works inside your files — not just in a chat window.

Install the Claude Code extension

1

Open the Extensions panel in VS Code

Look at the left sidebar — click the icon that looks like four squares (one slightly offset from the others). Or use the keyboard shortcut: Ctrl+Shift+X on Windows, Cmd+Shift+X on Mac.

2

Search for "Claude Code"

A search bar appears at the top. Type Claude Code. In the results, find the one published by Anthropic — that's the official one. Click the blue Install button next to it.

3

Find the Claude icon in your sidebar

After it installs, a new icon appears in the left sidebar — it looks like a small Claude logo (a stylized "C" or sparkle). Click it to open the Claude panel on the right side of your screen.

4

Sign in to your Anthropic account

In the Claude panel, click Sign In. Your browser will open and ask you to log in at claude.ai. Use the same account you use on claude.ai. You'll need either a Claude Pro or Max subscription (starting at $20/month at claude.ai) or an API key from console.anthropic.com.

How Claude Code is different from claude.ai The claude.ai website is just a conversation. Claude Code is an agent — it can open folders, create files, run scripts, and build things directly on your computer. When you give it a task, it does the actual work, not just talks about it.

Open your .claude folder in VS Code

Claude stores all your skills and personal notes in a hidden folder on your computer called .claude. Think of it as Claude's memory drive — everything it learns about you lives here. Open it in VS Code so you can see what Claude builds for you over time.

First time? Create the folder first The .claude folder doesn't exist until you use Claude Code for the first time. Before opening it, type anything in the Claude panel — even just "hello" — then come back to do the steps below. Claude will have created the folder automatically.
1

Go to File → Open Folder

In VS Code, click File in the top menu bar, then click Open Folder. A file picker window will open.

2

Navigate to your .claude folder

The folder is hidden by default on both Mac and Windows. See below for how to find it on your system.

Mac

In the file picker, press Cmd+Shift+G. A small "Go to folder" box appears. Type exactly: ~/.claude and press Enter. The folder will open.

Alternatively, press Cmd+Shift+. in the file picker to show hidden files and folders — then navigate to your home folder (named after your Mac username) and click .claude.

Windows

In the file picker, click inside the address bar at the top and type the full path: C:\Users\YourName\.claude — replacing YourName with your Windows account name (the name on your Start menu). Press Enter.

If you can't find it in File Explorer, open File Explorer, click View in the top menu, then check the box for Hidden items.

3

Click Open (or Select Folder)

VS Code will reload and now show your .claude folder in the left panel. This is your workspace — every skill, memory file, and setting Claude creates will appear here.

03

INSTALL THE SKILL CREATOR

The Main Event

A skill is a file you create once that tells Claude how to handle a specific type of task — every single time. Instead of re-explaining a job from scratch in every conversation, you build a skill and Claude just knows how to do it going forward.

The Skill Creator is a special skill made by Anthropic that helps you build, test, and improve any other skill you want to create. Once it's in your .claude folder, you can use it to build as many new skills as you like.

Get the Skill Creator file

The Skill Creator is a text file that Anthropic distributes as part of Claude Code. There are two ways to get it:

Option A — Ask Claude to install it for you (easiest) Open the Claude panel in VS Code and type exactly this: "I want to build custom skills. Can you help me get the skill-creator set up in my .claude folder?" Claude will walk you through where to get the file and how to place it.
Option B — Download from claude.ai Log in at claude.ai. Click on your profile or look in the left sidebar for a Skills section. Find the Skill Creator skill published by Anthropic and download it. The file will be a text file — save it to your Downloads folder.

Place the file in the right folder

Whether you used Option A or B, the Skill Creator file needs to live in a specific location inside your .claude folder. Here's how to set it up:

1

Create the skills folder

In VS Code with your .claude folder open, right-click anywhere in the left file panel and choose New Folder. Name it exactly: skills (all lowercase).

2

Create a skill-creator folder inside it

Right-click on the skills folder you just made and choose New Folder again. Name this one: skill-creator (all lowercase, hyphen between the words).

3

Move the file into that folder and name it SKILL.md

Drag the downloaded file into the skill-creator folder. The file must be named SKILL.md — that's what Claude looks for. If it downloaded with a different name (like skill-creator.skill or skill-creator.txt), right-click it in VS Code, choose Rename, and change the name to SKILL.md.

4

Confirm the structure looks right

In the VS Code left panel, you should see: .claude → skills → skill-creator → SKILL.md. If it looks like that, you're done.

5

Tell Claude you're ready to build

Open the Claude panel in VS Code and type: "I just installed the skill-creator. I want to build my first skill." Claude will read the file and guide you through the whole process from there — you won't need to do any manual setup.

Why the folder structure matters Every skill lives in its own named folder inside .claude/skills/. The instructions for each skill live in a file called SKILL.md inside that folder. Claude automatically finds and reads any skill placed here — there's no other configuration needed.
What your .claude folder looks like after this step
.claude/
  skills/
    skill-creator/
      SKILL.md          # ← the file you just installed
    your-next-skill/    # ← Claude will build new ones here
      SKILL.md
  memory/               # ← Claude stores notes about you here automatically
  CLAUDE.md             # ← your permanent preferences (Claude reads this every session)
What is CLAUDE.md? CLAUDE.md is a file Claude reads at the start of every conversation. You can use it to tell Claude things like: your name, what your business does, how you like responses formatted, words you never want it to use. You don't need to create it right now — Claude will create it for you when you first build a skill and fill in the relevant details.

How the skill building process works

Once the skill creator is installed, building a new skill takes 10–20 minutes. Always start with Prompt Anything — it designs the logic before Claude builds anything.

Go to promptanything.io first

Log in or create a free account at promptanything.io. This is where you design the logic of your skill before handing it to Claude to build. Describe what you want the skill to do in plain language — "I want something that takes a video transcript and writes Instagram, LinkedIn, and TikTok captions in my voice."

Prompt Anything structures it for you

It applies a proven framework to your rough idea and turns it into a clear, structured prompt — with a role, context, step-by-step instructions, and output format already defined. Test it directly in the tool until the output looks right. Adjust the wording until you're happy with it.

Bring it to Claude Code as a skill

Copy your finished prompt from Prompt Anything. Open the Claude panel in VS Code and say: "Turn this into a skill." Paste the prompt. The skill creator takes it from there.

Claude writes and tests it automatically

Claude creates the skill file, runs 2–3 test cases, and opens a results viewer in your browser so you can see the actual output side by side. No extra steps from you at this point.

Give feedback in plain language

In the viewer, type what you'd change — "make the tone more casual", "shorten the LinkedIn version", "never start with 'I'". Claude rewrites the skill and retests. Usually 1–2 rounds when you started with Prompt Anything.

The skill is live — permanently

The finished skill sits in your .claude/skills/ folder. Claude uses it automatically any time the situation matches — no commands to run, no reminders needed. Ever.
